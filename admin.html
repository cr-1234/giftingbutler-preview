▾ 📦 One-click add — bookmarklet for adding products from any store
Drag this button to your browser's bookmarks bar — 📦 Add to GiftingButler then, while viewing any single product's page — on Amazon, Walmart, Target, or most other stores — click it to open this admin with the title, price, photo, and description already filled in. Works best tuned for Amazon; other sites use each store's standard product data, so results may vary a bit by site.
If dragging doesn't work (common on mobile, or some browsers block it):
Manual setup instructions
  1. Bookmark any page in your browser (e.g. the star icon in the address bar).
  2. Edit that new bookmark and click into its URL/Location field. Clear whatever's there.
  3. Type the letters javascript: yourself (don't paste it — this part matters, see warning below).
  4. Click "Copy bookmarklet code" above, then paste (Ctrl+V) right after the javascript: you typed.
  5. Rename the bookmark to something like "Add to GiftingButler" and save.

⚠️ Important: most browsers auto-delete the word "javascript:" if you paste it — that's a security feature to stop malicious links. You must type those 11 characters yourself, then paste only the part after it. If your bookmark ends up opening a Google search instead of doing anything, this is why — redo it, typing "javascript:" by hand this time.

On a phone, this only works in browsers that let you edit a bookmark's URL (Safari and Chrome both do, under bookmark edit).
